# sapphire-agent-cli

The command line of [sapphire-agent](https://github.com/sapphire-turtle/sapphire-agent)'s
two editions: its commands (`serve`, `chat`, `acp`, `init`, `verify`, and sapphire-framework's
`status`, `service`, `workspace`, …), as a library.

To install the command, see [`sapphire-agent-headless`](../../headless/README.md) (no GUI)
or the desktop app; both put `sapphire-agent` on PATH. Up to 0.8 this name was the CLI's
binary crate.
